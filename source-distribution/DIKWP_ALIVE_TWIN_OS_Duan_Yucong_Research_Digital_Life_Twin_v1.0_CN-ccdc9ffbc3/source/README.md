# DIKWP-ALIVE TWIN OS v1.0

**段玉聪科研数字生命、功能性人工意识与证据孪生系统**

ALIVE = Auditable · Lineage-aware · Intentional · Viable · Evolving。

本系统不是人格克隆。它以段玉聪公开专业科研语料为初始种子，把论文、仓库、专利、标准、批评和实验转化为可追溯 ArtifactCell 与 ClaimGene，通过 DIKWP-Mesh 4.0 语义闭合、有限全局工作空间、自我模型、假设演化、实验工厂和行动防火墙，形成一个会修复、会被反驳、会版本化继承的科研数字生命。

## 快速运行

```bash
python runtime/alive_twin_runtime.py demo
python -m unittest discover -s tests -v
```

直接打开 `prototype/index.html` 可使用离线驾驶舱。

## 核心边界

- 默认仅使用公开专业材料。
- 输出分为文献事实、透明推断、生成研究、授权行动四层。
- 未经签名，不代表段玉聪本人发言。
- 不证明主观体验，不产生人的价值分数，不执行高影响决定。
- 所有新假设必须有证伪条件，所有公开结论必须有证据与残余。

## 目录

- `docs/`：最终 Word 技术总规范
- `prototype/`：单文件离线交互原型
- `runtime/`：Python 标准库参考运行时
- `schemas/`：七类 JSON Schema
- `data/`：公开样例语料
- `examples/`：确定性运行结果
- `tests/`：单元测试
- `assets/`：原创架构图
- `references/`：来源快照
